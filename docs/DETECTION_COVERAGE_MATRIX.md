# Detection Coverage Matrix

## Suspicious file coverage

| Format/evidence                           | Current behavior                                                                                                    | Classification limits                                                                 | Tested                                                               |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| ZIP                                       | Magic detection, bounded entry names/sizes, encrypted flag, nesting, risky names, traversal names, expansion limits | Contents are never extracted; encrypted contents remain inconclusive                  | Harmless document entries, nested archive, nested executable, limits |
| ISO                                       | ISO-9660 magic detection at the primary volume descriptor                                                           | Never mounted or traversed; metadata-only result is inconclusive                      | Synthetic ISO signature fixture                                      |
| EXE/SCR/COM                               | PE magic and extension mismatch; certificate-table presence                                                         | Certificate presence is not signature trust or validity                               | Synthetic renamed MZ fixture                                         |
| DLL/OCX/CPL                               | PE DLL characteristic where parsable                                                                                | Same signature limitation; malformed PE may be generic PE                             | Cross-build/fixture coverage, native validation pending              |
| MSI                                       | OLE/MSI detection when `.msi` and OLE magic agree                                                                   | MSI signature validation unsupported                                                  | Synthetic MSI/OLE signature fixture                                  |
| LNK                                       | Shell Link CLSID/header magic                                                                                       | Target parsing is not implemented                                                     | Synthetic Shell Link header fixture                                  |
| PowerShell/batch/JS/VBS/shell/Python/Perl | Extension/shebang classification and optional literal rules                                                         | No script execution or behavioral emulation                                           | Harmless literal-rule fixture                                        |
| Documents/images                          | Known PDF/RTF magic and extension comparisons                                                                       | Office Open XML is ZIP and reported as ZIP unless container-aware refinement is added | Legitimate text and PDF/RTF paths                                    |
| Password-protected ZIP                    | Encrypted flag and scan limitation                                                                                  | No password bypass; no content verdict                                                | Synthetic encrypted-entry metadata fixture                           |
| SHA-256 intelligence                      | Exact local hash lookup                                                                                             | Feed provenance and confidence are administrator supplied                             | Synthetic confirmed hash fixture                                     |
| Online reputation                         | Disabled by default                                                                                                 | No automatic hash or file disclosure                                                  | Not configured                                                       |

## Integration coverage

The isolated application/database test covers valid enrollment, expired/reused codes, device authentication, token revocation, heartbeat persistence, heartbeat replay, assessment persistence/idempotency, finding creation/retrieval, and tenant isolation. pgTAP separately checks RLS, grants, schema access, replay uniqueness, owner access, and absence of permissive public policies.
